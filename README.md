# KAALIYE V2

**Shaqo hel. Shaqaale hel.**

V2 starts with a polished Flutter Home Screen based on the approved KAALIYE reference.

## Included
- KAALIYE header and location
- Search/filter bar
- 4 primary action cards
- 12 service/job categories
- Bottom navigation
- Responsive layout
- Centralized app colors

## Run
1. Create/open a Flutter project.
2. Replace `pubspec.yaml` and the `lib/` folder with these files.
3. Run `flutter pub get`.
4. Run `flutter run`.

This is the UI foundation. Navigation/backend will be connected in later steps.
